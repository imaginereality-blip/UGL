# Replay v0.7.3: new name and icon

UGL is now **Replay**, with the subtitle *Ultimate Game Launcher*.

## Changes

- **New app icon.** A play button inside a replay arrow, used for the exe, the taskbar and the window.
- **Renamed to Replay** in the window title, startup splash, first-run welcome text, Settings help text and README.
- Release ZIPs are now named `Replay-portable-vX.Y.Z.zip`. In-app updating is unaffected: it picks up any `.zip` asset.

## Notes

- The executable is still `UGL.exe`, and the GitHub repo and your existing install folder are unchanged, so updating from v0.7.2 works as before.
